# Security Invariants → Enforcement and Evidence

Source: the brief's non-negotiable list (§54) and the skills pack's
`trust-platform-security-invariants.md`. "Evidence" paths are relative to the repo root.

| Invariant                                                                        | How it is enforced                                                                                                                                            | Evidence                                                                                                                                                                     |
| -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Never distribute private signing keys in client apps                             | `sdk-core` may import only `@trust/crypto/verify`; boundary checker also fails on any PEM private-key block in the tree; trust bundle exports public JWK only | `tools/check-boundaries.mjs`; `packages/crypto/test/jws.test.ts` ("trust bundle never contains private members"); `docs/api/lease-test-vectors.json` test (no `"d"`/PRIVATE) |
| Never trust client-provided subscription state                                   | Entitlements are server-resolved and delivered only inside signed leases; no endpoint accepts plan/entitlement input from devices                             | `packages/sdk-core/test/lease-verifier.test.ts` ("payload edited"); `services/platform-api/test/api.test.ts` (schemas strict)                                                |
| Never authorize sensitive operations only in the frontend                        | All authorization is in `AuthService`/`LicensingService`; no frontend exists in V1                                                                            | `tests/security/tenant-and-privilege.test.ts`                                                                                                                                |
| Never treat a serial number as authority                                         | License key selects a license; activation also needs session membership **and** device proof                                                                  | `packages/licensing/test/activation.test.ts` ("authority is not the key alone"); `tests/security` ("key alone is not authority")                                             |
| Never use IP address as sole device identity                                     | Device identity = Ed25519 key thumbprint; no IP-based identity anywhere                                                                                       | `packages/licensing/src/service.ts` (activation), `device-key.ts`                                                                                                            |
| Never store external cloud passwords                                             | No external-cloud integration in V1 (Milestone 5 will use OAuth/OIDC only)                                                                                    | n/a — design rule recorded in ADR-001 consequences                                                                                                                           |
| Never disable security controls to fix integration problems                      | No bypass flags exist; test seams are explicit `unsafe…ForTest` methods outside the port                                                                      | `packages/audit/src/index.ts`                                                                                                                                                |
| Never log passwords, private keys, tokens, document content, or full credentials | `redact()` on audit metadata and signals; telemetry allow-list; logger redacts auth header; validation errors omit values; license key returned once          | `services/platform-api/test/api.test.ts` ("logs never contain…"); `packages/audit/test`; `packages/telemetry/test`                                                           |
| Never execute unsigned/unverified desktop updates                                | **Out of scope in V1** (no updater). Requirement carried into Milestone 3                                                                                     | — (open, tracked)                                                                                                                                                            |
| Never provide permanent broad admin privilege unnecessarily                      | V1 compromise: flat `platform_admin`, re-verified every request, reason mandatory, audited, tenant-explicit paths. JIT/dual control = Milestone 6             | `tests/security` ("operator role is re-checked per request"); threat model R-5                                                                                               |
| Licensing failure never destroys documents                                       | Platform returns states only; SDK degrades (`expired`, `clock_anomaly`) and never deletes                                                                     | `packages/sdk-core/test` ("no data loss path"); `services/platform-api/test/api.test.ts` ("degrades without destroying anything")                                            |
| Tenant isolation enforced server-side at every data boundary                     | `orgId` on all repo calls; composite FKs; 404-for-foreign                                                                                                     | `tests/security` ×4; `migration.db.test.ts` (cross-tenant FKs)                                                                                                               |
| Update clients defend against rollback/freeze                                    | Not applicable until updates exist (Milestone 3)                                                                                                              | — (open, tracked)                                                                                                                                                            |
| Telemetry excludes content/secrets                                               | Allow-listed attributes per event name; unknown names/attributes dropped                                                                                      | `packages/telemetry/test/telemetry.test.ts`                                                                                                                                  |
| Recovery designed and tested before incidents                                    | Designed (runbooks); **not yet rehearsed**                                                                                                                    | `docs/runbooks/*` (open, tracked)                                                                                                                                            |
| Hard invariants fail closed; soft controls degrade                               | Signature/revocation/tenant failures deny; missing signing key ⇒ no lease; production config refuses unsafe start                                             | `activation.test.ts` ("fails closed"); `config.test.ts`                                                                                                                      |
